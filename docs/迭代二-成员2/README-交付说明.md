# 迭代二成员2交付说明

本轮完成用户、物品、收藏的业务实现与回归，验证冻结后的在途流转取消、成交回滚和数据库重启保留。以[迭代一交付](../迭代一-成员2/README-交付说明.md)的代码和33条测试为基线。

| 范围 | 本轮结果 |
|---|---|
| 用户 | 注册区分用户名与学号重复错误码，自助注册拒绝管理员角色。改密校验原口令、新口令强度和重复口令，成功后换盐、清除失败计数和锁定时间并记审计日志。锁定到期后重新累计失败，冻结账号无法登录和发布。 |
| 物品 | 发布默认待审核。发布者才能修改内容，管理员可通过原入口审核或下架。已售或锁定的物品拒绝修改。赠送价格校验、图片路径与大小校验、修改日志和状态字段保护在服务层落地。 |
| 检索与收藏 | 分类、价格、成色下限、排序和分页可以组合，筛选同时作用于记录和总数。收藏切换后按实际记录刷新计数，记录与计数在同一事务提交或回滚。 |
| 冻结与重启 | 冻结出让方或受让方时，取消该账户的全部在途流转，释放仍锁定的物品并写操作日志。首次建库后，正常启动保留原数据。控制台演示使用自己的临时库和 CSV。 |

验收结果见[测试报告](01-测试报告.md)，接入方式和规则差异见[接口与联调交接](02-接口与联调交接.md)。
