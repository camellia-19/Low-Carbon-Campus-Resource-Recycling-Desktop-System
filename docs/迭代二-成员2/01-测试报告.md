# 迭代二测试报告

项目为低碳校园资源循环流转桌面系统，验收日期为 2026-11-19。环境为 Windows、JDK 25.0.2（编译目标 Java 17）、Maven 3.9.14、JUnit 5.10.2、SQLite JDBC 3.46.1.0 和 JaCoCo 0.8.14。

在仓库根目录执行：

```powershell
cd green-campus
mvn -Pcoverage verify
```

Maven 单测报告位于 `green-campus/target/surefire-reports/`，覆盖率报告位于 `green-campus/target/site/jacoco/`。本次使用仓库下的独立 Maven 缓存，测试临时目录也指定在工程构建目录下。覆盖率配置通过 Surefire 的 JVM 参数为测试进程加载 JaCoCo，见 [JaCoCo Maven 插件说明](https://www.jacoco.org/jacoco/trunk/doc/maven.html)。
