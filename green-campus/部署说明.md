# 部署说明（控制台演示与应用初始化）

适用对象：组员与验收人员。当前入口为 `edu.campus.recycle.Main`，提供控制台业务演示；Swing GUI待成员3实现。

第1～5节为当前操作方法，第6～7节保留迭代一历史结果。迭代二的实测结果见[成员2测试报告](../docs/迭代二-成员2/01-测试报告.md)。

## 1. 环境与目录

- JDK 17及以上，编译目标为Java 17。
- Maven 3.8及以上；首次构建需下载依赖。
- SQLite无需单独安装服务。Maven使用 `pom.xml` 指定的sqlite-jdbc版本，离线演示使用 `lib/sqlite-jdbc-3.42.0.0.jar`。
- 本文命令按Windows PowerShell编写，classpath分隔符为分号。

从仓库根目录进入工程：

```powershell
cd green-campus
```

以下Java构建和运行命令均在此目录执行。SQL脚本在工程的上一级 `db/`，配置文件和 `DbConfig` 默认值均为：

```properties
db.schema=../db/schema.sql
db.seed=../db/seed-data.sql
db.url=jdbc:sqlite:data/greencampus.db
```

Main 每次在系统临时目录中创建独立演示库，显式导入种子，生成的 CSV 与演示库保存在同一目录。终端打印两者路径。应用的 `AppController.bootstrapDatabase()` 打开配置中的持久化库，只对空库建表，默认关闭 `app.seed.on.start`。设为 true 仅在空库初始化时导入种子，用于联调环境。

## 2. Maven构建与运行

```powershell
mvn test
mvn -Pcoverage verify
java -jar target/green-campus-1.0.0.jar
```

`mvn -Pcoverage verify` 执行测试、打包并检查 Service 行覆盖率，报告位于 `target/site/jacoco/`。当前 JAR 入口为 `edu.campus.recycle.Main`。SQL 从外部路径读取，运行时需保留工程与上级 `db/` 的相对位置。

## 3. 无Maven时的离线运行

仓库已提供 `lib/sqlite-jdbc-3.42.0.0.jar`，该驱动保留入库。

```powershell
javac --release 17 -encoding UTF-8 -sourcepath src/main/java -d build/classes -cp "lib/sqlite-jdbc-3.42.0.0.jar" src/main/java/edu/campus/recycle/Main.java
java -cp "build/classes;src/main/resources;lib/sqlite-jdbc-3.42.0.0.jar" edu.campus.recycle.Main
```

手工classpath需包含 `src/main/resources`，否则配置文件不会加载，将使用代码默认值。离线启动不运行JUnit；完整测试使用第2节Maven命令，或自行配置JUnit运行环境。

## 4. 双击运行

双击本目录 `start.bat`，脚本自动将工作目录切换到自身所在目录，并按以下顺序运行：

1. 有 `target/green-campus-1.0.0.jar` 时直接运行已有Jar。
2. 否则检测Maven，执行 `mvn -q -DskipTests package` 后运行。
3. 未检测到Maven时，查找 `lib/` 或用户Maven缓存中的SQLite JDBC驱动，使用javac编译到 `build/classes` 后运行。
4. 缺驱动或编译失败时打印错误。

脚本不会验证已有Jar是否与最新源码一致，且Maven分支跳过测试。源码修改后的验收应使用第2节命令重新测试、构建。当前批处理使用代码页936；手工PowerShell运行的中文显示取决于终端编码。

## 5. 常见问题

| 现象 | 检查与处理 |
|---|---|
| 建库脚本不存在 | 在仓库根目录下的 `green-campus` 中运行，确认上级 `db/` 的两个SQL文件存在；也可使用start.bat |
| 配置修改不生效 | 手工启动时将 `src/main/resources` 加入classpath；运行Jar时需重新构建才能包含新配置 |
| No suitable driver found | 使用Maven打包依赖，或将SQLite JDBC驱动加入手工classpath |
| 程序运行成功但看不到新改动 | 已有Jar可能过期，重新执行Maven构建 |
| 需要重新验证演示 | 重新启动 Main 即可获得一套新临时演示库和 CSV |
| 持久化库结构不完整 | 启动报出缺少的表并保留数据。使用匹配版本的库或经团队确认的迁移脚本 |
| 中文乱码 | 检查终端与批处理编码是否匹配；现有start.bat设置代码页936 |
