# 接口与联调交接

## 用户与物品

- `UserService.register(..., role, ...)` 保持原签名。空角色默认 STUDENT，现有 TEACHER 仍可使用，ADMIN 仅由受信方式预置，自助注册返回 PERM-001。同学号重复返回 DUP-002，同用户名重复返回 DUP-001。
- `UserService.changePassword` 的原口令错误、新口令过弱和与原口令相同分别返回 VAL-003、VAL-002 和 VAL-008。冻结账号登录返回 BR-03。连续失败锁定返回 LOCK-001，文案给出等待时长。改密成功记 CHG_PWD。
- `ItemService.publish` 默认 PENDING，旧的 DRAFT 选项仍可提交；直接传 ON_SALE 或其他流转状态会被拒绝。通过原审核入口上架。AppController 发布时以登录会话为所有者，其他接入层也需从会话传递操作者。
- `ItemService.updateItem(item, operatorId)` 采用 D1 权限矩阵，只有本人可编辑内容。管理员通过已有审核、下架入口管理他人物品。更新入口用 PERM-011 表示非发布者，用 NF-011 表示目标缺失。已售或被锁定时返回 BR-05。审计原因、上架时间、状态和计数以库内值为准。
- `publish` 和 `updateItem` 使用一致的字段规则。FREE 非零价格返回 VAL-004，物品字段或图片校验失败返回 VAL-011。图片参数仍为 `List<String>`，可传空列表。非空时传工作目录下图片存储目录内已经存在的相对路径，例如 `data/images/book.png`。每项大小大于 0 且不超过 2 MiB，最多5项，支持 jpg、jpeg、png 扩展名。选择、复制与重命名由调用方负责。
- `ItemQuery` 增加可选 `Integer conditionMin`，将其设置为 1～10 可按成色下限检索，与分类、价格区间、关键字及排序叠加。null 表示不限。价格端点含边界，允许区间为 [0, 100000]。非法价格区间或成色返回 VAL-005。该字段是相对迭代一类图的有意扩展。
- `FavoriteService.toggle` 的 true 仍表示收藏、false 表示取消，找不到物品返回 NF-021。每次切换以库内收藏记录校准计数。
- 冻结账户后取消全部 APPLYING、AGREED 流转，并记录原因、结束时间和日志。仅 AGREED 对应仍为 LOCKED 的物品恢复 ON_SALE。已完成流转保持原状态，解冻后不会复活已取消的流转。

## 启动与复现数据

成员3接入应用时使用 `AppController.bootstrapDatabase()`，该入口在配置的库上只建立首次结构，默认关闭演示数据。已有完整库按原数据打开。部分结构缺失时启动返回错误，需按后续迁移方案处理。

成员1可直接使用迭代一完整 SQLite 库，表结构和已有列与迭代一相同。数据库脚本重复运行保留已存在的业务数据，演示种子只在显式首次初始化时导入。真实部署的管理员开户、初始分类和配置由组内另行确定；演示预置账号仅供联调库使用。

从工程目录执行 `mvn package` 并运行 `java -jar target/green-campus-1.0.0.jar`，每次生成单独的演示库。终端第1步和第9步会分别打印 SQLite 文件与 CSV 路径。自动测试各自建临时空库，使用合成账号和明确的物品、流转预期，便于重复执行。
